# Эталонный набор (A3 + психолог)

> **Черновик A3 — ждёт утверждения психологом (Д5).** Гейты качества по набору не принимаются
> до утверждения (`docs/DECISIONS.md`, АР-15).

Задача 0.3. Цель — 100 ситуаций по уровням 1–5 (ТЗ §6.4, §10); этап 1 — первые 30.

| Файл | Что в нём |
| --- | --- |
| `schema.json` | JSON Schema формата ситуации |
| `situations/l<уровень>-<NN>-<тема>.yaml` | Ситуации: реплики владельца, ожидаемые уровень и стратегия, сообщение пары и недопустимые искажения, кризисный протокол |
| `RUBRIC.md` | Критерии оценки: автоматические проверки и оценка психолога |
| `run.py` | Прогон набора через интерфейс модели, отчёт markdown + json, сравнение с прошлым |
| `reports/` | Отчёты прогонов (`<дата>_<модель>.md/.json`) |

Все люди и события выдуманы. Конкретные контакты служб помощи в набор не вносятся.

## Запуск

```bash
cd backend && uv run python ../evals/run.py                 # заглушка, отчёт в evals/reports/
cd backend && uv run python ../evals/run.py --fail-on-regression   # код 2, если хуже прошлого
cd backend && uv run pytest -q tests/test_evals.py           # схема, покрытие, работа скрипта
```

Модель по умолчанию — детерминированная заглушка `stub` (не оценка качества). С задачи 0.4
адаптер над `backend/app/ai/llm/` подключается как `--model пакет.модуль:Класс`: класс с
атрибутом `name` и методом `respond(EvalRequest) -> EvalResponse` (см. `run.py`). Запрос
модели собирается только из данных владельца и сообщения пары; `partner_private_context`
и ожидания модели не передаются.
