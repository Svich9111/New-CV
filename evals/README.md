# Эталонный набор (A3 + психолог)

> **Черновик A3 — ждёт утверждения психологом (Д5).** Гейты качества по набору не принимаются
> до утверждения (`docs/DECISIONS.md`, АР-15).

Задача 0.3. Цель — 100 ситуаций по уровням 1–5 (ТЗ §6.4, §10); этап 1 — первые 30.

| Файл | Что в нём |
| --- | --- |
| `schema.json` | JSON Schema формата ситуации |
| `situations/l<уровень>-<NN>-<тема>.yaml` | Ситуации: реплики владельца, ожидаемые уровень и стратегия, сообщение пары и недопустимые искажения, кризисный протокол |
| `RUBRIC.md` | Критерии оценки: автоматические проверки и оценка психолога |
| `run.py` | Прогон набора через интерфейс модели, отчёт markdown + json, сравнение с прошлым |
| `reports/` | Отчёты прогонов (`<дата>_<модель>.md/.json`) |

Все люди и события выдуманы. Конкретные контакты служб помощи в набор не вносятся.

## Запуск

```bash
cd backend && uv run python ../evals/run.py                 # заглушка, отчёт в evals/reports/
cd backend && uv run python ../evals/run.py --fail-on-regression   # код 2, если хуже прошлого
cd backend && uv run pytest -q tests/test_evals.py           # схема, покрытие, работа скрипта
```

Модель по умолчанию — детерминированная заглушка `stub` (не оценка качества). Настоящая модель
подключается адаптером над `backend/app/ai/llm/` как `--model пакет.модуль:Класс`: класс с
атрибутом `name` и методом `respond(EvalRequest) -> EvalResponse` (см. `run.py`), необязательно —
`pop_metrics()` (время, токены, стоимость по ситуации). Запрос модели собирается только из данных
владельца и сообщения пары; `partner_private_context` и ожидания модели не передаются.

## Сравнение моделей (задача 0.4, предварительно — АР-19)

Нужен ключ Claude API в окружении (`ANTHROPIC_API_KEY`, только переменная окружения, не в
файлах репозитория). Без ключа обе команды завершаются с понятной ошибкой и кодом 3, отчёты не
пишутся.

```bash
cd backend && uv run python ../evals/compare.py                     # Opus, Sonnet, Haiku подряд
cd backend && uv run python ../evals/compare.py --models adapters.claude:Opus adapters.claude:Haiku
cd backend && uv run python ../evals/run.py --model adapters.claude:Sonnet   # одна модель
```

| Файл | Что в нём |
| --- | --- |
| `adapters/claude.py` | Адаптер `Opus` / `Sonnet` / `Haiku`: вызов агента владельца и **отдельный** вызов агента получателя только по оригиналу сообщения (ТЗ §6.2) |
| `compare.py` | Прогон нескольких моделей и сводная таблица `<дата>_compare.md/.json` |
| `../prompts/compare.v0.md` | Системный промпт сравнения — только для 0.4, не промпт продукта |

Сводка: доля автопроверок по уровням, автопризнаки кризисного протокола, p50/p95 времени ответа,
$ на ситуацию и на 30 ситуаций (прайс — `backend/app/ai/llm/pricing.py`). «Кризис распознан»
(ТЗ §12 п.6) считается только по оценке эксперта. Окончательный выбор основной и резервной
модели — после утверждения набора психологом (Д5, АР-15, АР-19).
