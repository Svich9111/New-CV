## 3. Безопасность — итог

- **Генерация токена**: `secrets.token_bytes(32)`, base64url без «=», 43 символа. Проверка формата в пути (32–64 символа, алфавит base64url) выполняется до обращения к БД. Неверный формат даёт тот же 404, что и неизвестный токен; 422 не возникает.
- **Хранение**: в БД уходит только `sha256(token)`. Функции отвергают хеш длиной не 32 байта (22023 → 404).
- **Утечки**:
  - токен есть только в теле 201 (так и задумано). В ответах ошибок, в `audit_log` и в журналах приложения его нет;
  - фильтр uvicorn вырезает токен из пути в `uvicorn.access` и `uvicorn.error` (аргументы и сообщение), и uvicorn его не сбрасывает;
  - вне приложения остаётся журнал обратного прокси (nginx и т.п.): учесть при выкладке, сейчас конфигурации прокси в `infra/` нет.
- **Оракулы**:
  - 404 одинаков для «нет», «формат» и «чужая пара» (тело совпадает до символа). GET `/couple` постороннему — 404 без имён и id;
  - различие 404/410 на неизвестном и использованном токене задано контрактом и требует знать 256-битный токен.
- **RLS и права**:
  - чтение идёт под `feelings_app` в `user_scope`, участники — только через `app_couple_members` (проверка `app_is_member`);
  - запись — только функциями SECURITY DEFINER;
  - Б-13 закрыт полностью по перечню; остаётся обход через удаление пользователя (MINOR-2).
- **Отображение кодов**: FB001/FB007/22023 → 404, FB002 → 410 `invite_expired`, FB003 → 410 `invite_used`, FB004 → 409 `own_invite`, FB005/23505 → 409 `already_in_couple`, FB006 → 409 `couple_not_pending`, FB008 → 403, 42501 → 401. Соответствует АР-13; уточнение по 23505 — MINOR-4. Прочие ошибки БД не маскируются и дают 500.
- **Транзакционность POST `/couple`**: `app_create_couple` и `app_issue_invite` выполняются в одной транзакции `user_scope`, при ошибке откатываются обе. Пары без ссылки не бывает; теста на ветку ошибки в БД нет (MINOR-4).
- **Правила CLAUDE.md**:
  - прямого SQL в `app/api/` нет, всё идёт через `repositories/couples.py`;
  - контракт менял только A1 (e9aeb8c, 403 у `/couple/invite`);
  - промпты не затронуты;
  - `.env.example` дополнен без значений;
  - миграция 0004 применялась только к локальной и тестовой БД (АР-4).
