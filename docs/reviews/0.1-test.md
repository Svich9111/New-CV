## Дефекты

- [MINOR] `frontend/tsconfig.tsbuildinfo` — артефакт сборки `tsc -b` закоммичен, а в `.gitignore` его нет. Из-за этого после `npm run lint` или `build` при изменённом наборе файлов рабочее дерево становится «грязным». Воспроизведено: после временного файла `src/neg.ts` команда `git status` показала `M frontend/tsconfig.tsbuildinfo`. Ожидается: удалить файл из индекса и добавить `*.tsbuildinfo` в `.gitignore`. Основание: карточка 0.1 «пустая сборка», чистота репозитория.
- [MINOR] `infra/docker-compose.yml:9` — создаётся БД `POSTGRES_DB: feelings`, а тесты по умолчанию идут в `feelings_test` (CLAUDE.md, раздел «Команды»; `ci.yml` `TEST_DATABASE_URL`). После `make db-up` тестовой базы нет, и первые тесты с БД (0.7) упадут локально. Ожидается: создавать и `feelings_test`, например init-скриптом, либо согласовать имя по умолчанию. Основание: карточка 0.1 «docker-compose для локальной БД».
- [MINOR] `frontend/package.json` — `npm audit` находит 15 уязвимостей в dev-зависимостях: critical у `vitest@2.1.8`/`tinypool` (исправлено в `vitest@2.1.9`), high у `vite@5.4.21`; кроме того, `eslint@9.17.0` помечен deprecated. В production-зависимостях (`npm audit --omit=dev`) — 0. Ожидается: поднять `vitest` до 2.1.9 и при необходимости обновить vite/eslint. Основание: ТЗ §9.1.

Блокирующих и существенных дефектов нет. Тестов не добавлял: каждый критерий проверяется командой.
