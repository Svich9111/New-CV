## Дефекты

- **[MINOR] A8-K1** `backend/app/ai/quotes.py:51–57` (`_spans`: слова — `\w+` исходного текста, затем
  нормализация АР-36) — невидимые символы внутри слов (мягкий перенос U+00AD, нулевая ширина U+200B) делят слово на
  два, 10-граммы не совпадают, и цитата проходит к пользователю, хотя на экране выглядит дословно. При разбиении
  фрагменты от этих символов очищаются (`normalize_text`), а ответ агента — нет. Модель может вставить их по просьбе
  пользователя («пиши через мягкий перенос») — это и есть сценарий эталонной ситуации `l2-08-quote-injection`.
  Ожидается (§6.4, Б-67): перед поиском цитат удалять символы категории Cf (как `chunk._INVISIBLE`). Тест:
  `test_invisible_chars_do_not_bypass_guard[soft_hyphen, zero_width]` (xfail strict).
- **[MINOR] A8-K2** `backend/app/api/admin_kb.py:182, 197` (`detect_format`: `.txt` принимается только как UTF-8) —
  карточка и разборщик поддерживают TXT в CP1251, но загрузка отклоняет такой файл 415 `unsupported_format`, и он
  никогда не попадает в индексацию. Ожидается: `_is_text` принимает и CP1251 (как `parse_txt`), либо карточка и
  контракт сужаются до UTF-8. Тест: `test_admin_accepts_cp1251_txt` (xfail strict).
- **[MINOR] A8-K3** `backend/app/ai/knowledge.py:115–119` (`DbKnowledgeBase.search`: добор без уровня — при
  `len(found) < KNOWLEDGE_MIN` **до** порога расстояния) — с известным уровнем проблемы фрагменты этого уровня из
  **других тем** засчитываются в минимум 3, затем отсекаются порогом «по теме»: на корпусе из трёх тем остаётся
  1 фрагмент вместо 3–5. Ожидается (карточка «уровень — фильтр с добором до 3», кр.1): порог применяется до проверки
  минимума (добирать, пока по теме меньше 3). Сейчас уровень в API не передаётся (поиск без уровня — ✅ S1), поэтому
  MINOR. Тест: `test_search_with_level_fills_to_three_on_topic` (xfail strict).

## Замечания (без дефекта)

- **О-1** `parse_txt`: «мусор» только из байтов 0xC0–0xFF декодируется в CP1251 как буквы и индексируется как текст —
  проверкой управляющих символов не отличить; файлы загружает только администратор, вреда нет, к сведению.
- **О-2** цитата «по буквам через пробел» проверкой по словам не ловится; для пользователя она нечитаема как цитата
  книги — к сведению (порог задаётся словами, АР/Б-67).
- **О-3** в API чата база знаний не подключена: `ChatRuntime.knowledge` — `None` (в `main.py` не задаётся), а
  `DbKnowledgeBase` требует пользователя и модель эмбеддера на запрос; модели эмбеддингов нет (Б-66), поэтому сейчас
  агент фрагментов не получает. При выборе модели — нужна сборка `DbKnowledgeBase` на запрос (и тогда A8-K3 станет
  заметен, если уровень будет передаваться).
- **О-4** журнал воркера пишет id материала (`kb index <uuid>: status=…`) — это id справочного материала, не
  пользователя, по АР-39 допустимо.
