## 4. Замечания

**[MINOR-1]** `frontend/src/admin/boundary.test.ts:248-262` — правило «глобальный объект только как
`объект.свойство`» пропускает цепочки, которые снова возвращают глобальный объект: `window.window`, `globalThis.globalThis`,
`self.self`, `window.top`/`parent`/`frames`, `document.defaultView`. Кроме того, деструктуризация `{ fetch: f }`
считается объявлением (`isDeclarationName`, `:146`) даже вне параметров. n1, n2, n10: все стражи зелёные, сетевой вызов
к `/api/v1/…` (путь собран через `join`) есть в бандле. Ожидание (карточка 2.8 п.2, р.2 MINOR-1):
(а) `G.X`, где `G` из `GLOBALS`, а `X` из `GLOBALS` или равно `defaultView`, — нарушение;
(б) имя свойства `fetch` в `ObjectBindingPattern` вне параметров функции (`const { fetch } = …`, `const { fetch: f } = …`)
— обращение к `fetch`;
(в) на каждое правило пример «страж падает» (n1, n2, n10).

**[MINOR-2]** `frontend/src/admin/boundary.test.ts:110-112, 265-272` — запрет `Function` и строковых таймеров
обходится без нужных идентификаторов: `(() => 0).constructor`, `Object.getPrototypeOf(async function () {}).constructor`
(n3, n4), `const st = setTimeout; st(code)` и `setTimeout.call(null, code)` (n5, n6). В продуктиве их гасит CSP без
`'unsafe-eval'`, но для `/admin/` её ещё нет (Б-100). Ожидание: доступ к свойству `constructor` в коде панели —
нарушение; `setTimeout`/`setInterval` — только в позиции вызываемого выражения (не значением, не `.call`/`.apply`).
Сюда же пример «страж падает». Вместе с Б-100 стоит проверить, что CSP панели не содержит `'unsafe-eval'`.

**[MINOR-3]** `frontend/src/admin/boundary.test.ts:270, 152-170, 253-261` — ложные срабатывания на законном коде
(§3):
- fp1, fp2: `setTimeout(resolve, ms)` и `setInterval(tick, …)`. Ожидание: пропускать идентификатор, объявленный
  локально как параметр, функция или переменная с инициализатором-функцией; запрещать строки, шаблоны, склейку и
  прочие идентификаторы;
- fp3: `declaredLocally` не учитывает `import { top/parent/self/frames }`. Ожидание: учитывать `ImportDeclaration`
  того же файла;
- fp4: имя атрибута JSX (`JsxAttribute.name`) — это не обращение к значению. Ожидание: добавить его в `isDeclarationName`;
- fp5: `typeof window` в выражении — допустить, как `typeof fetch` в типе.

На каждое исправление добавить строку в тест «без ложных срабатываний» (`:425-435`).

**[MINOR-4]** `frontend/src/admin/adminBuild.test.ts:101-114` — содержимое проверяется только у JS-чанков. CSS-ассеты
панели (`admin-….css`) на строки-пути не проверяются, и n9 (`url("/api/v1/memory")` в `admin.css`) проходит. Вред
небольшой (GET без заголовка авторизации, CSP `img-src 'self'` пропускает), но перечень путей сборки задуман для всего
вывода панели. Ожидание: применить те же регулярные выражения путей к ассетам `.css`, на которые ссылаются
достижимые чанки (`chunk.viewedMetadata.importedCss`).

Остаточный риск без отдельного замечания: инъекция `<script>` с путём, собранным во время работы (n11), и вообще
любое вычисление во время работы статически не закрывается. Защищает сервер: админ-токен даёт только `/admin/*`.
