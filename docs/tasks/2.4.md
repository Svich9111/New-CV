## Ограничения сейчас

- Кредиты OpenRouter исчерпаны: модели извлечения и сжатия — заглушки в тестах, промпты (`memory_extract.v0`,
  `memory_merge.v0`, `profile_summary.v0`) — черновики без прогона (АР-26); качество извлечения — после кредитов и психолога.
- Модель эмбеддингов не выбрана (Б-66): запись векторов — через интерфейс `Embedder` (заглушка в тестах).

## Границы

Этап 1 (A3 + A1 при необходимости):
- **Сессия** (Б-54): правило деления диалога на сессии (по паузе, по дате) — опиши и реализуй; извлечение запускается
  по окончании сессии (фоновая задача, без блокировки ответа; при перезапуске — догоняет).
- **Извлечение** (§6.3 п.1, ФТ-12): из реплик владельца сессии — записи типов §6.3 (факт, дата, предпочтение,
  чувствительная тема, наблюдение — отдельно и с пометкой, `source = agent_observation`), с источником, датой,
  уверенностью; текст шифруется (4.2); вектор — `app_set_memory_embedding`.
- **Из сообщений партнёра** (ФТ-14): только одобренные и доставленные владельцу сообщения пары (`source = from_partner`,
  связь с сообщением), никогда — личный чат или память партнёра.
- **Слияние** (§6.3 п.1, п.3): новая запись обновляет/объединяет существующую (без потери источника), дубликаты
  не плодятся.
- **Недельное сжатие** (§6.3 п.3): объединение дубликатов, обновление сводки профиля (`agents.profile_summary_enc`).
- **Удалённое не возвращается** (§6.3 п.4, §2 п.6): отпечатки удалённых записей (колонка `fingerprint` из 0001 —
  проверь схему), повторное извлечение, слияние и сжатие сверяются с ними; удаление обнуляет `text_enc`, `embedding`,
  `embedding_model` вместе (CHECK 0008); Б-53 / АР-31 — сводка диалога и сводка профиля пересобираются без удалённого
  по правилу АР-31 (до решения оператора — при ближайшем сжатии).
- **Б-63** (A1): вне функций — только обнуление вектора и модели; **Б-64**: сбой поиска памяти не обрывает
  `read_context` (точка сохранения, откат на свежесть, снять страж A8-V1); **Б-65**: `LIMIT 1001` вместо `count(*)`.

Этап 2 (A2): `GET /memory` (по категориям, только свои, наблюдения помечены, источник и дата), `DELETE /memory/{id}`
(204/404, запись не восстанавливается — через функцию слоя доступа, отпечаток сохраняется), журналы без текстов.

Не входит: экран памяти (2.5), база знаний (2.6), выбор модели эмбеддингов.

## Критерии готовности

- [x] Удалённая запись не возвращается: ни повторным извлечением из старых диалогов, ни слиянием, ни сжатием, ни в контекст (критерий RoadMap).
- [x] Память партнёра недоступна: извлечение и контекст — только данные владельца и одобренные сообщения пары (критерий RoadMap).
- [x] Типы, источник, дата, уверенность; наблюдения отделены от слов владельца.
- [x] Слияние без дубликатов; недельное сжатие обновляет сводку профиля без удалённого.
- [x] Фоновые задачи не блокируют ответ, догоняют после перезапуска, не дублируют работу.
- [x] `GET/DELETE /memory` по контракту; журналы без текстов.

## Тесты

Этап 1 (A3) — `backend/tests/test_memory_worker.py` (заглушка модели, `HashingEmbedder`; захват — `feelings_worker`,
обработка — роль входа `feelings_api` → `user_scope`):
- отпечаток: нормализация и формат АР-36, ключ из окружения (`FEELINGS_MEMORY_FINGERPRINT_KEY`), прежние ключи;
  `texts.add_memory_item` пишет отпечаток (Б-68);
- извлечение: виды, источник, дата, уверенность (наблюдение — `agent_inference`, ≤ 0.6), вектор и модель, отметка
  сессии; в модель — только реплики владельца (ответы агента и id — нет); незавершённая сессия не берётся;
- изоляция (ФТ-14, §9.2): личный чат и память партнёра, его оригиналы, `processing`/`withheld`, свои отправленные —
  не в модели; из пары — доставленное владельцу (версия, которую он видел), запись `from_partner` со ссылкой;
  только текущая активная пара (АР-37: сообщения распавшейся пары не извлекаются); реплики владельца и сообщения
  партнёра — раздельные вызовы, источник задаёт код (ревью MINOR-2);
- удалённое не возвращается: старая сессия не обрабатывается повторно (отметка); то же содержание в новой сессии
  (регистр, «ё», пунктуация) — отпечаток; **перефразировка другими словами — не ловится** (ограничение АР-36,
  зафиксировано тестом); запись, удалённая во время слияния, — итог слияния не пишется; удалённое — не в контексте;
- слияние: точный повтор — уверенность, без дубликата; близкая запись — одна запись (новый отпечаток и вектор);
  другой вид/источник не сливается;
- сжатие: дубликаты убраны, близкие слиты, сводка профиля — только из живых записей; сводка диалога, помеченная
  удалением и не переписанная задачей очистки, обнуляется с сохранением отметки (АР-37; сверка с прочитанным —
  ревью MINOR-5);
- воркер: недоступность — повтор после аренды, вторая копия во время аренды не берёт; попыток больше предела —
  завершение без извлечения; отказ модели — завершение без записей; две копии — одна запись (перехваченная аренда →
  откат); удаление аккаунта во время работы — `gone`; полный проход `run_once` — извлечение и сжатие, повторный
  проход пуст, журнал без текстов и id;
- Б-64: имя модели > 128 и компонента вне float4 — проверка до запроса; отказ БД (22023) — точка сохранения, память
  по свежести (страж A8-V1 `test_context_db_rejected_vector_falls_back` без xfail);
- промпты `memory_extract.v0`, `memory_merge.v0`, `profile_summary.v0`, `summary_forget.v0` — черновики без
  прогона (АР-26).
- Раунд 1 (АР-37): удаление `memory.forget_memory` — профиль обнулён, сводки диалога «на очистку» (не в контексте и
  не в выгрузке) сразу; `run_forget` переписывает **перефразированную** сводку без удалённого и пересобирает профиль;
  сбой задачи — сводка обнулена с отметкой; две пометки — сводка скрыта до очистки обеих; сжатие чата не берёт
  помеченную прежнюю сводку; длинная сессия — пачки (MINOR-3), предел попыток — журнал `error`; страж xfail(strict)
  `test_delete_queues_compaction_outside_period` — постановка на сжатие вне периода (функция БД, A1). Тесты A8
  (`test_memory_a8.py`) — ожидания по АР-37 и MINOR-2 обновлены с пометкой «2.4 р1 (A3)».
