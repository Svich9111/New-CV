## Ограничения сейчас

- Кредиты OpenRouter исчерпаны: модели извлечения и сжатия — заглушки в тестах, промпты (`memory_extract.v0`,
  `memory_merge.v0`, `profile_summary.v0`) — черновики без прогона (АР-26); качество извлечения — после кредитов и психолога.
- Модель эмбеддингов не выбрана (Б-66): запись векторов — через интерфейс `Embedder` (заглушка в тестах).

## Границы

Этап 1 (A3 + A1 при необходимости):
- **Сессия** (Б-54): правило деления диалога на сессии (по паузе, по дате) — опиши и реализуй; извлечение запускается
  по окончании сессии (фоновая задача, без блокировки ответа; при перезапуске — догоняет).
- **Извлечение** (§6.3 п.1, ФТ-12): из реплик владельца сессии — записи типов §6.3 (факт, дата, предпочтение,
  чувствительная тема, наблюдение — отдельно и с пометкой, `source = agent_observation`), с источником, датой,
  уверенностью; текст шифруется (4.2); вектор — `app_set_memory_embedding`.
- **Из сообщений партнёра** (ФТ-14): только одобренные и доставленные владельцу сообщения пары (`source = from_partner`,
  связь с сообщением), никогда — личный чат или память партнёра.
- **Слияние** (§6.3 п.1, п.3): новая запись обновляет/объединяет существующую (без потери источника), дубликаты
  не плодятся.
- **Недельное сжатие** (§6.3 п.3): объединение дубликатов, обновление сводки профиля (`agents.profile_summary_enc`).
- **Удалённое не возвращается** (§6.3 п.4, §2 п.6): отпечатки удалённых записей (колонка `fingerprint` из 0001 —
  проверь схему), повторное извлечение, слияние и сжатие сверяются с ними; удаление обнуляет `text_enc`, `embedding`,
  `embedding_model` вместе (CHECK 0008); Б-53 / АР-31 — сводка диалога и сводка профиля пересобираются без удалённого
  по правилу АР-31 (до решения оператора — при ближайшем сжатии).
- **Б-63** (A1): вне функций — только обнуление вектора и модели; **Б-64**: сбой поиска памяти не обрывает
  `read_context` (точка сохранения, откат на свежесть, снять страж A8-V1); **Б-65**: `LIMIT 1001` вместо `count(*)`.

Этап 2 (A2): `GET /memory` (по категориям, только свои, наблюдения помечены, источник и дата), `DELETE /memory/{id}`
(204/404, запись не восстанавливается — через функцию слоя доступа, отпечаток сохраняется), журналы без текстов.

Не входит: экран памяти (2.5), база знаний (2.6), выбор модели эмбеддингов.

## Критерии готовности

- [ ] Удалённая запись не возвращается: ни повторным извлечением из старых диалогов, ни слиянием, ни сжатием, ни в контекст (критерий RoadMap).
- [ ] Память партнёра недоступна: извлечение и контекст — только данные владельца и одобренные сообщения пары (критерий RoadMap).
- [ ] Типы, источник, дата, уверенность; наблюдения отделены от слов владельца.
- [ ] Слияние без дубликатов; недельное сжатие обновляет сводку профиля без удалённого.
- [ ] Фоновые задачи не блокируют ответ, догоняют после перезапуска, не дублируют работу.
- [ ] `GET/DELETE /memory` по контракту; журналы без текстов.
