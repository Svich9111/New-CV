## Границы

Входит: продуктовые промпты v0 в `prompts/` (отдельный файл на роль, версия в имени, заголовок с назначением и
разделами ТЗ): агент владельца — диалог (`dialog.v0.md`), черновик «чувство — ситуация — потребность — просьба»
(`draft.v0.md`); конвейер — классификатор безопасности (`safety.v0.md`), оценка тона 0–3 (`tone.v0.md`), адаптация
(`adapt.v0.md`), контроль смысла (`meaning.v0.md`); кризисный ответ (§9.3) — шаблон без смягчения.
Модуль `backend/app/ai/` (например `pipeline.py`, `dialog.py`, `prompts.py` — загрузка промптов по версии):
чистые функции над слоем LLM, без БД — на вход только то, что разрешено §6.1/§6.2 (агент получателя — только
одобренный оригинал; кризис — без адаптации; при расхождении смысла — оригинал с предупреждением). Консольный
прототип `python -m app.ai.demo` (или `evals/demo.py`): сценарий «Анна и Игорь» — диалог Анны, черновик,
одобрение, конвейер, доставка Игорю; выдуманные данные.
Прогон эталонного набора на промптах v0 (skill run-evals, через OpenRouter, потолок расходов ≤ $5, модель — по
гипотезе АР-19: Sonnet для диалога/адаптации, Haiku для классификаторов) и отчёт в `evals/reports/`.
Не входит: БД, сборка контекста из памяти и базы знаний (2.1, 2.4, 2.6 — здесь контекст подаётся аргументами),
потоковый ответ, интерфейс, окончательный выбор модели (после психолога, АР-19).

## Критерии готовности

- [ ] Промпты v0 по всем ролям; принципы §2 и запреты §6.2 п.5 явно в тексте; текст сообщения партнёра подаётся как данные, не инструкция (защита от внедрения инструкций).
- [ ] Конвейер: безопасность → (кризис: стоп, без адаптации, направление к специалистам) → тон → адаптация при 2–3 → контроль смысла → при расхождении оригинал + предупреждение; ни одно сообщение не уходит без явного подтверждения в прототипе.
- [ ] Агент получателя получает только оригинал (тест-«эхо», как в 0.4b); данные автора (диалог, память) в запрос конвейера не попадают — тест.
- [ ] Сценарий «Анна и Игорь» проходит в консоли (критерий RoadMap); вывод без идентификаторов.
- [ ] Прогон эталонного набора на v0 (все 31 ситуация), отчёт и сравнение с compare.v1; кризисные ситуации — 8/8.
- [ ] Модульные тесты без сети (заглушка провайдера): маршрутизация конвейера, кризис, расхождение смысла, отказ модели (АР-20), ошибки JSON.
