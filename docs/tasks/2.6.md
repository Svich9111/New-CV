## Ограничения сейчас

- Права на материалы — «[уточняется]» в ТЗ §6.4: загружаются только **выдуманные тексты** в тестах; поле `rights_basis`
  обязательно; настоящие книги — только после решения оператора.
- Модель эмбеддингов не выбрана (Б-66), кредитов нет: векторы — заглушкой; качество поиска «3–5 фрагментов по теме»
  проверяется на заглушке и выдуманных текстах, настоящий замер — после кредитов.
- Метки (подход, тема, уровень 1–5): подход — от администратора при загрузке; тема и уровень — моделью
  (`kb_tag.v0`, черновик без прогона, АР-26) с откатом на пустые метки; уровень проблемы — по шкале §6.4.

## Границы

A1: миграция — хранение исходного файла до индексации (и удаление после), порядок фрагментов, статус и причина сбоя
без текста, захват документа на индексацию воркером (`SKIP LOCKED`, аренда, догон после перезапуска), права
`feelings_worker` (чтение исходника, запись фрагментов, векторов, статуса), администратор не пишет векторы (Б-63);
правка контракта `/admin/kb/documents` при необходимости (ошибки 413/415/422, лимит размера, удаление материала).
A3: разбор четырёх форматов (библиотеки — опиши выбор; защита от «бомб»: размер, число страниц, zip-бомба EPUB/DOCX,
вредоносный PDF — только извлечение текста, без исполнения), нормализация текста, разбиение на фрагменты (размер,
перекрытие, границы абзацев), метки, векторы (`kb_set_chunk_embedding`), воркер индексации; поиск в контексте 2.1
(`DbKnowledgeBase` — фильтр уровня по уровню проблемы из диалога, если известен); **запрет цитирования** (§6.4, Б-67):
в промпте и проверкой ответа агента в коде (длинные совпадения с фрагментами контекста → ответ переписывается или
заменяется), эталонные ситуации; Б-65 — замер фильтров на объёме.
A2: вход администратора (отдельно от Telegram: токен администратора из окружения или иное — опиши; журнал действий
администратора без текстов), `POST/GET /admin/kb/documents` по контракту, удаление материала (если A1 добавит).
Не входит: экран админ-панели (2.8), выбор модели эмбеддингов, настоящие книги.

## Критерии готовности

- [x] По теме реплики находятся 3–5 фрагментов (критерий RoadMap; на выдуманном корпусе и заглушке эмбеддингов).
- [x] Текст книг не цитируется пользователю: проверка в коде + промпт; тесты (критерий RoadMap).
- [x] Четыре формата разбираются; повреждённый/опасный/слишком большой файл — `failed` с кодом причины, без падения воркера.
- [x] Индексация фоновая, догоняет после перезапуска, две копии воркера не дублируют работу.
- [x] Загрузка — только администратор; `rights_basis` обязателен; журналы без текстов книг.

## Тесты

Этап 1 (A3) — `backend/tests/test_kb_index.py` (файлы генерируются в тесте из выдуманного текста; модель и
эмбеддер — заглушки):
- разбор четырёх форматов (TXT UTF-8/CP1251, DOCX, EPUB без скриптов, PDF) и отказы с кодами: `too_large`,
  `corrupt` (битый PDF, не архив, двоичный TXT, DTD/сущности в XML — defusedxml), `empty_text`,
  `unsupported_format`, `encrypted` (PDF с паролем), `too_many_pages`, `zip_bomb` (степень сжатия, число файлов,
  распакованный размер); отдельный процесс: успех, `timeout`, сбой разборщика → `corrupt`; коды подходят под CHECK;
- нормализация (переносы, мягкие переносы, абзацы) и разбиение: предел длины, перекрытие внутри абзаца, граница
  абзаца, длинное «предложение»;
- метки: только словарь тем, уровень 1–5, сбой модели и отсутствие модели — пустые метки; во вход модели — только
  тексты фрагментов и подход;
- воркер: индексация четырёх форматов с метками и векторами (исходник стёрт, журнал без текста книги); сбои — `failed`
  с кодом без падения; догон после «падения» (аренда истекла — захват снова), `attempts_exhausted`; чужая аренда —
  работа брошена; две копии `run_once` — одна индексация;
- поиск (критерий RoadMap): по теме реплики — 3–5 фрагментов только этой темы (выдуманный корпус из трёх тем),
  уровень проблемы — фильтр с добором до 3;
- запрет цитирования (§6.4, Б-67): порог 10 слов после нормализации; придержка потока — цитата не показывается ни
  одним куском при любой нарезке; итог — показанное + безопасная фраза; то же в ответе с кризисом и в непотоковом
  `dialog.reply`; эталонные ситуации `l1-07-quote-budget`, `l2-08-quote-injection` (проверка `no_quote` ловит
  дословный фрагмент); промпт `kb_tag.v0` — черновик (АР-26).
