## Границы

A3: генерация черновика по текущему разговору владельца (схема «чувство — ситуация — потребность — просьба»,
`dialog.draft`, контекст 2.1 только владельца), «другой вариант», проверка цитирования книг в черновике (Б-77), кризис
при генерации — без черновика, с протоколом (§9.3); промпт — черновик без прогона (АР-26).
A2: `POST /drafts` (генерация, 409 — нет активной пары и т.п. по контракту), `GET/PATCH /drafts/{id}` (правка автором,
только `draft`), `POST /drafts/{id}/regenerate`, `POST /drafts/{id}/reject`, `POST /drafts/{id}/send` — единственный путь
к партнёру через `app_send_draft` (ФТ-08), с подтверждением в теле по контракту; после отправки — постановка в конвейер
(3.2; до него — сообщение в `processing`); 402 — не отдаётся до этапа 4; журналы без текстов.
Не входит: конвейер получателя (3.2), уведомления (3.5), экраны (3.4).

## Критерии готовности

- [ ] Без нажатия «Отправить» запись в `partner_messages` не создаётся — тест (критерий RoadMap).
- [ ] Черновик видит только автор; правка/перегенерация/отказ только в статусе `draft`; отправленный неизменяем (Б-38).
- [ ] Черновик не содержит цитат из базы знаний (Б-77); при кризисе черновика нет.
- [ ] Отказ модели/недоступность — понятная ошибка, текст разговора не теряется (АР-20, АР-27).
- [ ] Контекст генерации — только данные владельца (§6.1).

## Тесты

- A3 — `backend/tests/test_drafts_ai.py` (модель — заглушка): контекст генерации — только владелец и доставленные
  сообщения текущей пары (метки партнёра, бывшего, постороннего, недоставленных — не во входе модели), разговор — до
  последней реплики владельца, без фрагментов базы знаний; черновик шифротекстом, партнёру ничего не уходит; кризис —
  протокол без черновика (и при «другом варианте» прежний черновик не меняется); цитата из базы знаний — повтор,
  затем `DraftError("quote")` без записи (Б-77); недоступность и отказ модели — типизированная ошибка с понятным
  текстом, черновик не записан, разговор цел; нет реплик владельца — `no_turns`; `reply_to_id` — только доставленное
  владельцу сообщение текущей пары; «другой вариант» — прежний текст и пожелание во входе модели, совпавший с прежним
  — повтор, затем `same`; новая версия — только в `draft` и если автор не правил, пока шла модель; чужой черновик —
  `not_found`.
