## Границы

Входит: статический кликабельный прототип в `frontend/prototype/` (HTML + CSS + немного JS, без сборки и
без внешних зависимостей), открывается с телефона; все 11 экранов §8 и переходы ключевого сценария §1
на выдуманных данных; светлая и тёмная тема.
Не входит: настоящий Mini App (1.5), запросы к API.

## Критерии готовности

- [x] Есть все экраны таблицы §8: Приветствие (3 слайда), Онбординг, Приглашение, Главный, Чат с агентом,
      Черновик, Сообщения пары, Память, Профиль и пара, Подписка, Помощь.
- [x] Ключевой сценарий §1 проходится кликами: Анна пишет агенту → агент отражает чувство и уточняет →
      «Подготовить сообщение» → черновик «чувство — ситуация — потребность — просьба» → правка / «Другой вариант» /
      «Не отправлять» / «Отправить» → у Игоря входящее с пометкой «адаптировано» → «Показать оригинал» →
      «Ответить с агентом».
- [x] Палитра §8: фон #FFFFFF и тёплый светло-серый, текст #111111, акцент #E11D2E только для главного действия
      и близости; красный не используется для ошибок; сообщения владельца — чёрная плашка, агента — светлая,
      партнёра — белая карточка с красной линией слева; тёмная тема.
- [x] Состояния дублируются подписью, а не только цветом; есть пояснение «партнёр этого не видит» на экране памяти;
      на «Приветствии» и «Помощи» — что продукт не заменяет психолога (§8, §9.4).
- [x] Ни одно сообщение партнёру в прототипе не «уходит» без нажатия «Отправить» (§2 п.2).
- [x] Вёрстка под телефон 360–430 px, без горизонтальной прокрутки; имитация главной кнопки и кнопки «назад» Telegram.
- [x] Тексты на русском, тон агента по §2: тёплый, на «ты», без канцелярита и морализаторства.

## Тесты

- `frontend/prototype/check.mjs` — проверка Playwright: каждый экран открывается, ключевой сценарий проходится
  кликами, нет горизонтальной прокрутки на 375 px, скриншоты светлой/тёмной темы в `frontend/prototype/screens/`.

Результат A4: открыть `frontend/prototype/index.html` (файлом или с телефона через любой статический
сервер); панель над «телефоном» переключает сторону «Анна / Игорь», тему и экран. `node frontend/prototype/check.mjs` —
202 проверки, все пройдены (после раунда 2); скриншоты пишутся во временный каталог, закоммиченные
`frontend/prototype/screens/{light,dark}-*.png` обновляются флагом `--update-screens`. Кризисные контакты на «Помощи»
и цены на «Подписке» — выдуманные заглушки до закрытия [уточняется] (§9.3, §11). Проверка на телефоне — оператор, гейт Г1.
