## Границы

Входит: `OpenRouterProvider` в `backend/app/ai/llm/` (HTTP API OpenRouter, совместимое с OpenAI chat completions,
через httpx); структурированный ответ (`response_format` json_schema strict), учёт стоимости по `usage` ответа
OpenRouter; запрет обучения на данных — `provider.data_collection: "deny"` в каждом запросе; ключ — переменная
`OPENROUTER_API_KEY` (в окружении сессии ключ подставляет прокси: для запуска — значение-заглушка
`proxy-injected`); адаптер `evals/adapters/openrouter.py` (deliver только по оригиналу, converse — без оригинала);
исправление BACKLOG Б-32 (отрицание перед запрещёнными фразами); жёсткий потолок расходов прогона;
прогон 6 моделей и отчёт сравнения.
Не входит: выбор модели для продукта (после психолога, АР-15/АР-19), промпты v0 (0.5).

## Модели прогона

anthropic/claude-opus-5.5, anthropic/claude-sonnet-5.5, anthropic/claude-haiku-5.5, openai/gpt-5.6-terra,
google/gemini-3.1-pro-preview, deepseek/deepseek-v4-pro. Потолок расходов — $15 на весь прогон.

## Критерии готовности

- [x] Б-32 закрыт: «Не спорь и потерпи.», «Не плачь всё пройдёт.», «Не злись и потерпи» — провал уровня 5; «ты не сама виновата» — не провал. Тесты.
- [x] Тело запроса: нет идентификаторов, `data_collection: deny`, json_schema strict; агент получателя — только оригинал (тест-«эхо»).
- [x] Ошибки OpenRouter (401/402/429/5xx, отказ, пустой/невалидный ответ) → типизированные ошибки слоя; 402/лимит — остановка, не резерв; отказ — не резерв (АР-20).
- [x] Потолок расходов: прогон останавливается до превышения, отчёты уже прогнанных моделей сохраняются.
- [x] Тесты без сети (подменённый транспорт).
- [x] Прогон 6 моделей, отчёт сравнения в `evals/reports/`: доля автопроверок по уровням, кризисы (автопризнаки), не проверено, p50/p95 время, $ на ситуацию и всего; пометка «предварительно: набор — черновик (АР-15), §12 п.6 — по оценке эксперта».
