## Границы

Входит (A1, миграция 0008): функции SECURITY DEFINER (`search_path = public, pg_temp`, `EXECUTE` только нужной роли,
пользователь — `app_uid()`, удалённый/чужой — 42501 или пусто):
- `app_memory_nearest(query, limit)` — ближайшие записи памяти своего агента (не удалённые, с текстом и вектором),
  порядок по косинусному расстоянию, предел; `app_set_memory_embedding(item, vec)` — вектор только своей неудалённой записи;
- поиск по базе знаний: `app_kb_nearest(query, limit, фильтры по меткам — подход, тема, уровень)` для `feelings_app`
  (база знаний — общая, не личная; текст фрагмента отдаётся агенту, пользователю не цитируется — §6.4); запись векторов
  фрагментов — роль воркера индексации (`feelings_worker`) или admin;
- индексы HNSW (`vector_cosine_ops`) на `memory_items.embedding` и `kb_chunks.embedding`;
- модель эмбеддинга: колонка `embedding_model` (или иное правило) в `memory_items` и `kb_chunks` — поиск только по
  векторам текущей модели (АР-5);
- права: прямой доступ приложения к функциям pgvector остаётся закрытым (параметр функций — `text` с приведением внутри,
  если иначе роль не может передать вектор — опиши).
Контракт (A1): `GET /help/contacts` — публичный (`security: []`, Б-58), снять страж `test_help_contacts_declares_401`
по новому смыслу (заменить на «доступно без сессии»); описание `GET /chat/messages`: на 422 по курсору после ротации
ключа — начать с первой страницы (Б-62).
A3 после A1: `_memory` в `repositories/chat.py` — через `app_memory_nearest`; страж
`test_app_role_has_no_pgvector_functions_yet` — заменить по смыслу; без эмбеддера — по свежести, как сейчас.
Не входит: выбор настоящей модели эмбеддингов (без кредитов не проверить), извлечение памяти (2.4), индексация книг (2.6).

## Критерии готовности

- [ ] Поиск по смыслу выполняется в БД с индексом; изоляция: чужая память, удалённая запись, вектор другой модели не возвращаются — тесты под ролями `feelings_app`/`feelings_api`/`feelings_worker`.
- [ ] Запись вектора — только своей неудалённой записи; удаление записи обнуляет вектор (CHECK 0001 соблюдён).
- [ ] Поиск по базе знаний с фильтрами по меткам; доступ ролей по назначению.
- [ ] Миграция обратима, `alembic check` чист; `/help/contacts` доступен без сессии.
