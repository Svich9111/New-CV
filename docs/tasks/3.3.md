## Границы

`GET /couple/messages` — лента пары (отправленные — оригинал автора; полученные — версия для получателя с пометкой
«адаптировано»; статусы «доставлено / прочитано / отвечено»; недоставленные получатель не видит; курсор),
`GET /couple/messages/{id}/original` — оригинал получателю, просмотр фиксируется, 409 conflict_retry,
`POST /couple/messages/{id}/read` — прочитано; «отвечено» — при отправке ответа (`reply_to_id`, 3.1); журналы без текстов.
Не входит: конвейер (3.2), экраны (3.4).

## Критерии готовности

- [ ] Просмотр оригинала фиксируется (критерий RoadMap); оригинал — только получателю доставленного сообщения.
- [ ] Лента: только своя пара (текущая; бывшая — по контракту), недоставленное получателю не видно, статусы верны.
- [ ] Нерасшифрованное — `UnavailableText`; журналы без текстов.
