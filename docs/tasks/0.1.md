## Границы

Входит: CLAUDE.md, описания агентов, команды, структура каталогов RoadMap §4, линтеры, пустая сборка
backend/frontend, CI, docker-compose для локальной БД, перенос ТЗ в `docs/TZ.md`.

## Критерии готовности

- [ ] Структура каталогов соответствует RoadMap §4.
- [ ] `docs/TZ.md` содержит полное ТЗ v1.0 (разделы 1–13, ФТ-01…ФТ-27, 17 таблиц).
- [ ] CLAUDE.md содержит стек, команды, 7 принципов и все жёсткие правила RoadMap §4.
- [ ] `.claude/agents/` — описания ролей A0–A8 с зонами и правилами.
- [ ] `make lint` и `make test` зелёные на пустом каркасе; `npm run build` собирается.
- [ ] CI запускает линтеры и тесты backend и frontend.
- [ ] Секреты не в репозитории: `.env` в `.gitignore`, есть `.env.example`.
