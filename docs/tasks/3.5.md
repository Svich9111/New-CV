## Границы

Воркер уведомлений: захват из очереди (`pipeline_claim_notify`, аренда, попытки), отправка получателю через
`notify_user` (чат ищется в момент отправки; удалённому/неизвестному — ничего, Б-47) — текст без содержания сообщения,
с кнопкой открытия Mini App (если `FEELINGS_WEBAPP_URL` задан); отметка `pipeline_notify_done`; ошибки Telegram:
429 (Retry-After), 403 (бот заблокирован — не повторять), сеть — повтор; исчерпание попыток — отметка без отправки;
журналы без текстов, токенов и chat_id. Запуск — отдельный процесс или вместе с конвейером (реши), сервис в compose
стенда с health check. Не входит: настройки уведомлений пользователя, оплата.

## Критерии готовности

- [ ] От отправки до уведомления ≤ 30 с (критерий RoadMap; на заглушках — конвейер + уведомление).
- [ ] В уведомлении нет текста сообщения, имени автора сверх необходимого (обсудить), id; только «новое сообщение от партнёра» и кнопка.
- [ ] Ровно одно уведомление на сообщение: две копии воркера, падение, повторы.
- [ ] Удалённый получатель, распавшаяся пара, заблокированный бот — без ошибок в журнале и без повторов.
- [ ] Журналы без текстов, токена бота, chat_id.

## Тесты

`backend/tests/test_notify_worker.py` (A5; Bot API — `httpx.MockTransport`, модель — заглушка):

- полный путь «Отправить» → конвейер → уведомление ≤ 30 с (оба воркера в непрерывном цикле);
- текст без содержания, имени автора и id; кнопка Mini App; без `FEELINGS_WEBAPP_URL` — без кнопки;
- ровно одно: две копии воркера, падение после захвата (повтор после аренды), перехват аренды
  (старый токен не отмечает), сбой отметки (повтор отметки, без второй отправки);
- сеть/5xx — повтор в пределах аренды; постоянный сбой — после аренды, исчерпание — отметка БД;
  тайм-аут чтения/обрыв — без повтора; 429 — пауза `retry_after`; 403/400 — отметка без повторов;
  401/404 — пауза без отметки;
- получатель удалён (до захвата и между захватом и отправкой), пара распалась — ничего не отправлено;
- журналы без текста, токена, chat_id, id и описания ошибки Telegram; настройки и compose.
